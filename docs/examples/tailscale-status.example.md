# Example — redacted `tailscale status` table

Copy this shape when publishing a new dump. Never paste raw CLI or JSON.

**Tailnet identity:** `name@example.com` (career or studio)  
**Date:** YYYY-MM-DD  
**Captured from:** hostname  
**MagicDNS:** `example.ts.net` (omit if you do not want the suffix public)

| Hostname | OS | Role | Online | Tags |
|----------|-----|------|--------|------|
| example-host | linux | control seat | yes | — |

Omit: IPs, relay city if you prefer, user numeric IDs, keys, last-seen timestamps that pinpoint a person.
