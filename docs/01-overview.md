LabNet is the lab. I installed Starlink, built the VyOS edge, expanded NIC count with USB Ethernet adapters, and kept LabNet separate from the rest of the premises. The machines in the inventory are the portfolio set: `um690`, `vyos-router`, and `node1`–`node3`.

## What this lab is for

- Learn Linux administration, networking, and IT operations on hardware I operate
- Keep that work on LabNet and the DestroyTheKraken tailnet, apart from personal devices
- Reach the lab without opening inbound WAN ports (Starlink CGNAT)
- Run Proxmox VE on `node1`–`node3` (installed; web UI observed 2026-11-15), then Prometheus and Grafana, then other services from the Proxmox UI
- Write runbooks that match what is actually running

## What this snapshot is not

Not a multi-tenant cloud. Not a client-hosting environment. Not an active local-IT business ([dtk](https://github.com/DestroyTheKraken/dtk) was a tooling experiment).
